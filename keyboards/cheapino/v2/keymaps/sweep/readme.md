# Mike's Cheapino V2 Vial profile

Generated by `sweep-layouts/build.py` from the Cheapino spec in `boards.py`. It replaces the earlier
`mikevial` build, which had QMK's default 16 macro slots: the layout uses 21, so STACK's M16-M20
(the left bottom row) came up blank.

- 14 dynamic layers and 32 macro slots, with the layout's keys and encoder compiled in as defaults.
- Original Cheapino V2 UID and 8x12 matrix, including the encoder button at `3,0`.
- Vial runtime settings, tap dance, combos, overrides and RGB controls.
- 8 KiB of emulated EEPROM backed by 16 KiB of RP2040 flash.
- Vial unlock: hold the outer thumb on each half (Num and Tab on the base layer).
- Bootmagic: hold Q (physical top-left key, matrix `4,10`) while connecting USB.
  This resets EEPROM and enters the bootloader; use BOOT/RESET for ordinary updates.

## Build

From `sweep-layouts`:

```sh
python3 build.py cheapino --compile
```

Output: `firmware/cheapino.uf2`.

## Flash and restore

1. Hold BOOT on the RP2040-Zero while connecting USB, or hold BOOT and press RESET.
2. Copy `cheapino.uf2` onto the `RPI-RP2` drive. It will reboot.
3. Open Vial and load `vil/cheapino.vil` to restore the complete configuration, including
   runtime settings. Unlock when prompted using the two outer thumb keys described above.
4. Check all 36 keys, encoder press and both turn directions, and the STACK layer's
   left bottom row, then save a fresh export.
