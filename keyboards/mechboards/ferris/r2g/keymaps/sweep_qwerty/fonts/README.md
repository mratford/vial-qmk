# Screen fonts

Generated by `screens.py` (`make_fonts`, via `qmk painter-make-font-image` and `painter-convert-font-image`,
mono4) whenever the legends need a glyph these don't have; `glyphs.txt` records what they were made with. Don't
edit them by hand.

Made from DejaVu Sans Condensed and DejaVu Sans Condensed Bold (the copies bundled with LibreOffice, see
`FONT_DIR` in `screens.py`). DejaVu fonts are under the Bitstream Vera Fonts licence with public-domain
changes: free to use, modify and redistribute. https://dejavu-fonts.github.io/License.html
